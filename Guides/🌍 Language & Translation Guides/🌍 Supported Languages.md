# 🌍 Supported Languages

Version 3.2 includes support for multiple dashboard and application languages.

The goal is to provide a World Cup experience accessible to users worldwide.

## Dashboard Support

Supported languages apply to:

* Dashboard Navigation
* Overview Page
* Live Centre
* Fixtures & Results
* Group Standings
* Knockout Centre
* Statistics Hub
* Tournament Records
* Stadium & Venue Information

---

## World Cup Application Support

The dedicated World Cup Application also supports language selection for supported interface elements.

## Requesting A Language

If your language is not currently supported, you can:

* Open a GitHub Issue
* Submit a Translation
* Create a Pull Request

Community contributions are always welcome.

The World Cup 2026 integration currently supports 12 languages and continues to expand through community contributions and future updates.
