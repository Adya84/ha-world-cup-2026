# 🌍 Adding New Translations

The World Cup 2026 integration supports community contributed translations.

If your language is not currently supported, you can help expand the project by creating a translation file and submitting it to the repository.

---

## Current Translation System

Translations are stored within the integration and loaded automatically by the dashboard and World Cup Application.

Supported text includes:

* Navigation Labels
* Dashboard Titles
* Statistics Names
* Records Labels
* Stadium Information
* Application Pages

---

## Creating A Translation

1. Fork the repository.
2. Locate the translation files.
3. Copy an existing language file.
4. Translate the text values.
5. Save using the correct language code.

Example:

```text
en.json
fr.json
de.json
es.json
```

---

## Testing Your Translation

After creating a translation:

1. Restart Home Assistant.
2. Select the new language.
3. Verify all translated text appears correctly.

---

## Submitting A Translation

Create a Pull Request on GitHub containing:

* New Translation File
* Language Name
* Language Code

The translation will be reviewed and added to a future release.

---

## Translation Guidelines

Please ensure:

* Translations are accurate.
* Football terminology remains consistent.
* Formatting is preserved.
* Special characters display correctly.

---

## Community Contributions

Community translations help make the World Cup 2026 integration accessible to more users around the world.

Thank you for contributing.
