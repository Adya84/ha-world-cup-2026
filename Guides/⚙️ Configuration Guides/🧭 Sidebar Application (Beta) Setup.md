# 🧭 Sidebar Application (Beta) Setup

Version 3.2 introduces the World Cup 2026 Application, a dedicated Home Assistant sidebar application providing quick access to tournament information, statistics and analytics.

⚠️ The sidebar application is currently considered **Beta** and may receive additional improvements in future releases.

---

# What Is The Sidebar Application?

The World Cup Application provides a dedicated interface separate from the standard dashboard.

It is designed to deliver a more app-like experience directly within Home Assistant.

Features include:

* Built-In Navigation
* Tournament Overview
* Live Centre
* Fixtures & Results
* Group Standings
* Knockout Centre
* Statistics Hub
* Tournament Records
* Stadium Information
* Multi-Language Support

---

# Accessing The Application

After installing the integration and restarting Home Assistant, a new sidebar item should automatically appear.

Look for:

```text
World Cup 2026
```

with a football icon.

Clicking the sidebar item launches the application.

---

# Automatic Installation

No additional configuration is normally required.

The integration automatically:

✅ Registers the sidebar panel

✅ Loads the World Cup application

✅ Creates navigation pages

✅ Connects to World Cup sensors

---

# Browser Cache

If the application does not update after an upgrade:

Refresh your browser using:

```text
Ctrl + F5
```

or clear your browser cache.

---

# Troubleshooting

## Sidebar Item Missing

Restart Home Assistant.

Then refresh your browser.

---

## Application Not Loading

Verify:

```text
Settings → Devices & Services
```

shows:

```text
World Cup 2026
```

loaded correctly.

---

## Blank Application Screen

Clear browser cache:

```text
Ctrl + F5
```

Then reload Home Assistant.

---

## Navigation Not Appearing

The sidebar navigation is still in Beta.

Restart Home Assistant and refresh the browser.
