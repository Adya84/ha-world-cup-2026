# 📊 Overview Page Guide

The Overview page is the main landing page of the World Cup 2026 Application.

It provides a quick snapshot of the current tournament status and key statistics, allowing users to see the most important information at a glance.

---

# Accessing The Overview Page

Open the World Cup 2026 Application from the Home Assistant sidebar.

Select:

```text
Overview
```

from the navigation menu.

The Overview page is normally displayed automatically when the application opens.

---

# What The Overview Page Shows

The Overview page combines tournament information, live data and key statistics into a single screen.

Information may include:

* Tournament Progress
* Matches Played
* Matches Remaining
* Live Matches
* Total Goals
* Group Information
* Current Tournament Stage
* Tournament Completion Percentage

---

# Tournament Progress

Displays how far the competition has progressed.

Examples:

```text
Tournament Progress
45%
```

This value updates automatically as matches are completed.

---

# Matches Played

Displays the number of completed matches.

Example:

```text
Matches Played
47
```

---

# Matches Remaining

Displays how many matches are left to be played.

Example:

```text
Matches Remaining
57
```

---

# Live Matches

Shows how many matches are currently in progress.

Example:

```text
Live Matches
2
```

When no matches are live the value will show:

```text
0
```

---

# Total Goals

Displays the total number of goals scored throughout the tournament.

Example:

```text
Total Goals
138
```

---

# Current Tournament Stage

Shows the current competition phase.

Examples:

```text
Group Stage
```

```text
Round of 32
```

```text
Quarter Finals
```

```text
Final
```

---

# Tournament Completion

Displays the percentage of the tournament completed.

Example:

```text
65%
```

This figure updates automatically after each completed match.

---

# Live Tournament Status

The Overview page updates automatically as new data becomes available.

During live matches the integration increases update frequency to provide faster updates.

---

# Troubleshooting

## No Data Displayed

Verify the integration is installed and running correctly.

Check:

```text
Settings → Devices & Services
```

and ensure the World Cup 2026 integration is loaded.

---

## Statistics Showing Zero

This can occur when:

* The tournament has not started
* No data has been received yet
* Demo Mode is disabled and live data is unavailable

---

## Page Not Updating

Refresh your browser:

```text
Ctrl + F5
```

or reload the integration.
