# 📈 Statistics Hub Guide

The Statistics Hub is one of the most powerful features of the World Cup 2026 Application.

It provides advanced tournament analytics, trends and performance metrics that go beyond basic fixtures and results.

Perfect for users who enjoy analysing the tournament in greater detail.

---

# Accessing The Statistics Hub

Open the World Cup 2026 Application from the Home Assistant sidebar.

Select:

```text
Statistics Hub
```

from the navigation menu.

---

# What The Statistics Hub Shows

The Statistics Hub provides a collection of advanced tournament metrics.

Information may include:

* Tournament Progress
* Matches Played
* Matches Remaining
* Total Goals
* Goals Per Match
* Draw Rate
* BTTS Rate
* Over 2.5 Goals Rate
* Live Match Count
* Tournament Completion Percentage

---

# Tournament Progress

Displays how far the tournament has progressed.

Example:

```text
Tournament Progress
42%
```

The value updates automatically as matches are completed.

---

# Matches Played

Displays the number of completed matches.

Example:

```text
Matches Played
44
```

---

# Matches Remaining

Shows how many fixtures are still to be played.

Example:

```text
Matches Remaining
60
```

---

# Total Goals

Displays the total number of goals scored during the tournament.

Example:

```text
Total Goals
132
```

---

# Goals Per Match

Calculates the average number of goals scored per game.

Example:

```text
Goals Per Match
3.00
```

Useful for identifying whether the tournament is becoming more or less attacking.

---

# Draw Rate

Shows the percentage of matches ending in a draw.

Example:

```text
Draw Rate
28%
```

This metric updates automatically throughout the tournament.

---

# BTTS Rate

BTTS stands for:

```text
Both Teams To Score
```

This statistic measures how often both teams score in the same match.

Example:

```text
BTTS Rate
57%
```

---

# Over 2.5 Goals Rate

Tracks the percentage of matches containing:

```text
3 Goals Or More
```

Example:

```text
Over 2.5 Goals Rate
61%
```

A popular statistic for analysing tournament trends.

---

# Live Match Count

Displays how many matches are currently being played.

Example:

```text
Live Matches
2
```

---

# Tournament Completion Percentage

Shows how much of the tournament has been completed.

Example:

```text
67%
```

Calculated automatically based on completed fixtures.

---

# Automatic Updates

Statistics update automatically whenever:

* Match Results Change
* New Fixtures Complete
* Tournament Data Refreshes

No manual updates are required.

The Statistics Hub is fully responsive and supports:

* Desktop
* Tablet
* Mobile Devices

Cards automatically adapt to available screen space.

---

# Troubleshooting

## Statistics Showing Zero

This may occur when:

* No matches have been completed
* The tournament has not started
* Demo Mode is disabled and no data is available

---

## Statistics Not Updating

Refresh your browser:

```text
Ctrl + F5
```

or reload the integration.

---

## Missing Statistics

Some statistics may only become available once sufficient tournament data exists.

For example:

```text
Draw Rate
```

and

```text
Goals Per Match
```

require completed fixtures.
